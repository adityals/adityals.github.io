Projects

A few things I've built and shipped.

  • MyFiltraNet alpha

    A DNS filter for Indonesian households: online gambling is blocked by default, with optional filters for fraud, fake, and adult content. One pro account splits into four profiles, the kids' devices can run strict while yours don't. Each with its own categories and custom domain list. Browsing history is never stored. Wrote the resolver and forwarder in Go, with the dashboard running as a HonoX app on Cloudflare Workers backed by Hyperdrive.

    Go Cloudflare Workers

    app.myfiltranet.com →

  • Shipplane

    A self-hosted workflow orchestrator that chains tasks into a DAG and runs as a single binary, with no database or extra infrastructure to stand up. Built the core state-machine engine and two ways to drive it: a CLI for the terminal and a web UI built on a framework-agnostic visualizer with React bindings for editing the graph.
